# JarvexAI - Frontend

This repository contains the frontend of the JarvexAI full-stack AI SaaS product. It is built with React and Vite to deliver a fast, modern, and responsive user interface.

---

## Tech Stack

- React 19
- Vite
- Tailwind CSS v4
- ESLint

---

## Getting Started

Follow these steps to run the frontend locally.

### 1. Prerequisites

Make sure you have [Node.js] installed.

### 2. Install Dependencies

Navigate to the `client` directory and run:

```bash
npm install
```

### 3. Start the Development Server

```bash
npm run dev
```

Once started, open the local URL displayed in your terminal.

### 4. Build for Production

```bash
npm run build
```
